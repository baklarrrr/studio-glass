# Studio Glass

<sub>BAKAR STUDIO / PERSONAL EXPERIMENT</sub>

A compact interface for checking studio status and reviewing images on wearable displays.

## Status

Experimental. Physical glasses interaction remains unverified. Connected studio features require additional components that are not included in this public interface repository.

[Project page](https://baklarrrr.github.io/studio-glass/) | [Bakar Studio](https://bakar.ca/)
